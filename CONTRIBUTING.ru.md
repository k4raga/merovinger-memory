# Участие в разработке

Merovinger Memory находится в альфе. Делайте небольшие изменения
и прикладывайте тестовый пример для воспроизведения.

1. Используйте Python 3.13 и виртуальное окружение.
2. Установите инструменты командой `python -m pip install build pytest`.
3. Соберите и установите wheel, затем выполните `python -I -B -m pytest -q tests`.
4. При изменении истории, сжатия или снимков запустите
   [пример сохранения и восстановления](docs/quickstart.ru.md#пример-сохранения).

Согласованно обновляйте русскую и английскую документацию.
Сохраняйте совместимость импорта `agent_native_memory`.
Документируйте намеренные изменения API и формата, обновляйте историю изменений.

Не добавляйте обязательные зависимости от модели и UI,
скрытые вызовы сжатия или автоматический повтор UNKNOWN.
Не коммитьте реальные диалоги, учётные данные, локальные окружения
и результаты выполнения. Используйте тестовые данные.
Объясняйте, что именно доказывает результат проверки и где его границы.

Код, собственная документация и иллюстрации доступны под [MIT](LICENSE).
