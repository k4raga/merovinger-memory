# Проверки

В репозитории есть самостоятельные тесты публичного фасада текстовой истории
и низкоуровневых значений, покрытия, применимости и подсчёта.
Данные тестовые; модель, UI, база данных и учётная запись не требуются.

CI настроен для Python 3.13 на Ubuntu и Windows. Наличие настроенного задания
не равно завершённой проверке платформы: смотрите фактические прогоны Actions.

Каждое задание собирает и устанавливает wheel, запускает тесты
и выполняет пример сохранения в двух новых процессах.
Пример проверяет сохранность полной истории, ограниченный контекст,
явное применение сводки, открытую группу и восстановление UNKNOWN.
Метаданные определяют пакет `merovinger-memory`;
пути импортов сверяются с установленной поставкой.

Локальные эквивалентные команды:

~~~sh
python -m pip install build pytest
python -m build --wheel
python -m pip install --force-reinstall dist/merovinger_memory-0.1.0a1-py3-none-any.whl
python -I -B -m pytest -q tests
~~~

Затем выполните две [команды примера](quickstart.ru.md#пример-сохранения).
Тесты импортируют установленный пакет без подставленного пути к исходникам.
Низкоуровневая проверка чистоты анализирует установленные pure-модули.

Эти проверки не доказывают точность токенов провайдера, надёжное выполнение
ровно один раз, промышленную готовность, поддержку произвольного протокола
инструментов или транзакций между сервисами.
Локальные отчёты и снимки не являются публичными фикстурами и должны
оставаться в игнорируемых Git файлах.

## Зафиксированная локальная проверка

17 ноября 2026 новое окружение Ubuntu с Python 3.13 собрало и установило
wheel этого репозитория: **128 тестов прошли** —
116 низкоуровневых, 11 для фасада и одна проверка поставки.
Обе команды примера в новых процессах прошли; оба Python-примера README
выполнены с установленным пакетом. Модель, UI и база данных не использовались.

Локальный прогон не выдаётся за Windows CI. Числа относятся к этой версии
исходников, а не к тесту производительности или промышленной гарантии.
